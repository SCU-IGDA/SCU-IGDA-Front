# 基础组件清单

## 1. 全局布局组件 (Layouts & Global)

这些组件定义了网站的整体框架，对应 PRD 中的导航栏和页脚。

| 组件名 | 建议路径 | 对应 PRD 描述 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **TheHeader.vue** | `components/App/Header.vue` | 图1.1 顶部导航栏 | 包含 Logo、顶部菜单（首页、活动、内容库）、登录/头像入口。 |
| **TheFooter.vue** | `components/App/Footer.vue` | (常规需求) | 放置版权信息、友情链接等。 |
| **AppContainer.vue** | `components/App/Container.vue` | - | 用于限制页面最大宽度并居中 (Tailwind `container mx-auto`)，保持页面布局统一。 |

## 💡 推荐集成的第三方库

为了实现 PRD 中的功能，除了自己写组件，您必须引入以下库：

1. **富文本编辑器 (必选)**:
    * **Tiptap** (推荐，Vue 支持极好) 或 **Quill**。
    * *用途*：实现 P6 图1.4 中的正文编辑、图片插入功能。
2. **Markdown 解析/渲染 (可选)**:
    * 如果您打算让用户写 Markdown 而不是富文本，可以使用 `@nuxtjs/mdc`。但根据 PRD "类似 B 站"，富文本（WYSIWYG）更合适。
3. **图标库**:
    * **Lucide-vue-next** 或 **Heroicons**。
    * *用途*：搜索图标、上传图标、点赞图标等。

## 🚀 开发优先级建议（基于 PRD）

1. **Level 1 (骨架)**: `TheHeader`, `TheFooter`, `AppContainer`.
2. **Level 2 (列表页)**: `BaseCard`, `PostListCard`, `CategoryTabs`.
3. **Level 3 (详情页)**: `PostDetailHeader`, `PostContentBody`.
4. **Level 4 (编辑器)**: `RichTextEditor`, `BaseImageUpload`.

你可以直接按照这个清单去创建 `.vue` 文件，这样工程架构会非常清晰。
