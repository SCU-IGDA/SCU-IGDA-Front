# 前端表单和数据结构

## 登录注册

注册：

```ts
const form = ref({
    username: '',           // 用户名
    email: '',              // 电子邮箱
    verificationCode: '',   // 验证码
    password: '',           // 密码
    confirmPassword: '',    // 确认密码
    agree: false            // 用户协议
})
```

登录：

```ts
const form = ref({
    email: '',        // 用户邮箱
    password: '',     // 用户密码
    remember: false   // 记住密码
})
```

## 帖子数据

```ts
export interface Post {
    id: string | number     // 帖子唯一标识
    title: string           // 帖子标题
    summary: string         // 帖子摘要
    cover?: string          // 帖子封面图片
    author: string          // 帖子作者
    date: string            // 帖子发布时间
    category: string        // 帖子分类
    views?: number          // 帖子浏览量
    likes?: number          // 帖子点赞数
}
```

## 帖子列表数据

```ts
interface Props {
    posts: Post[]         // 帖子数据
    loading: boolean      // 加载状态
    page: number          // 当前页码
    totalPages: number    // 总页数
}
```
