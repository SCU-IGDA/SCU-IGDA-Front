# 前端工程架构解释

## 项目概述

本项目基于 **Nuxt 3** 框架构建，使用 **Tailwind CSS** 进行样式开发。

## 目录结构详解

### 核心源码目录

| 目录/文件 | 说明 | 详细规范 |
| :--- | :--- | :--- |
| **`app.vue`** | **应用主入口** | 类似于传统 Vue 项目的 App.vue，负责定义页面的根结构（通常包裹 `<NuxtLayout>`）。 |
| **`pages/`** | **页面路由** | **自动路由**。该目录下的文件结构会自动映射为 URL 路由。<br> - `index.vue` → `/`<br> - `about.vue` → `/about` |
| **`layouts/`** | **布局模版** | 存放页面的通用外壳（如导航栏、页脚）。<br> - `default.vue`：默认布局，所有页面默认使用此布局。 |
| **`components/`** | **UI 组件** | 存放可复用的 Vue 组件。Nuxt 会**自动导入**此目录下的组件，无需手动 import。<br> - 建议按功能划分子目录，如 `components/Home/Banner.vue`。 |
| **`assets/`** | **静态资源 (编译)** | 存放需要构建工具处理的资源（CSS, Sass, 图片）。<br> - `css/main.css`：Tailwind 的入口文件及全局样式定义处。 |
| **`public/`** | **静态资源 (纯静态)** | 存放**不需要处理**的文件，直接映射到根域名下。<br> - 引用方式：`/favicon.ico` 或 `/robots.txt`。 |
| **`composables/`** | **组合式函数** | 存放 Vue Composables (Hooks)。<br> - 此目录下的函数也会被**自动导入**。<br> - 用于封装跨组件复用的逻辑（如状态管理、鼠标追踪等）。 |
| **`server/`** | **服务端接口** | 基于 Nitro 引擎的后端 API。<br> - 文件映射为 API 路由，如 `/server/api/hello.ts` → `/api/hello`。 |
| **`utils/`** | **工具函数** | 存放纯辅助函数（非 Vue 状态相关），如日期格式化、正则校验等。 |
| **`plugins/`** | **插件** | 在 Vue 应用挂载前运行的代码，用于集成第三方库（如统计代码、UI 库配置）。 |

### 配置文件

| 文件 | 说明 |
| :--- | :--- |
| **`nuxt.config.ts`** | **Nuxt 核心配置**。管理模块 (`modules`)、环境变量、SEO 配置等。 |
| **`tailwind.config.js`** | **样式配置**。定义 Tailwind 的主题颜色、断点、字体扩展等。 |
| **`tsconfig.json`** | **TypeScript 配置**。Nuxt 会自动生成 `.nuxt/tsconfig.json`，通常只需在此处扩展配置。 |
| **`package.json`** | **依赖管理**。定义项目脚本 (`dev`, `build`) 和依赖包版本。 |
